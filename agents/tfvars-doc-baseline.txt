# Variables that do not appear in their root's terraform.tfvars.example.
# Enforced by check_tfvars_docs in agents/check.sh: a variable missing from both
# the template and this file fails the gate, and an entry here that IS now
# documented (or deleted) also fails, so the list cannot silently rot.
#
# Two kinds of entry, deliberately in one file since the gate treats them alike:
#
#   1. Not customer-facing. The modules/*/app roots take most of their inputs
#      from the matching infra root's outputs, written by `make init-app`.
#      Putting those in a template invites hand-editing a generated value.
#
#   2. Documentation debt predating the gate. These should be documented and
#      the line deleted. Adding a line here is the wrong fix for new work:
#      a variable added today gets documented today.
#
# Format: "<root> <variable>", one per line.
