# Results fields

Generated by `make reference` (in `langsmith-sizing`) from the results documents the load test's own report builder writes.
Do not edit it; a test fails when it differs from the code. The schema is `langsmith-load-results/1`: adding a field does not
change that number, renaming or moving one does. `<class>` repeats once per read class.

| Path | Type | Unit | Meaning |
|:--|:--|:--|:--|
| `schema` | string | - | langsmith-load-results/1; it changes only when a field's name, place or meaning does |
| `test_id` | string | - | the unique id in every run's metadata; the stored count filters on it |
| `project` | string | - | the LangSmith project the run wrote to |
| `started_at` | string | - | when the load started, ISO 8601 UTC |
| `ended_at` | string | - | when the load and the stored count finished, ISO 8601 UTC |
| `profile` | object | - | the load profile the run used, as langsmith-sizing writes it (its fields are in langsmith-sizing/docs/fields.md) |
| `settings` | object | - | the options the run used |
| `settings.data_seed` | null | - | the seed of the generated text, or null for a random one |
| `settings.duration_seconds` | number | seconds | how long to send, including the ramp |
| `settings.feedback_drain_seconds` | number | seconds | how long to wait for feedback in flight after the load |
| `settings.lag_deadline_seconds` | number | seconds | a sampled trace not readable by now is never readable |
| `settings.lag_poll_seconds` | number | seconds | how often a sampled trace is polled |
| `settings.lag_sample` | number | fraction | the share of traces polled for send-to-readable lag |
| `settings.latency_limit_seconds` | number or null | seconds | the limit on the 95th-percentile send latency, or null for none |
| `settings.max_in_flight` | number | traces | unfinished traces allowed before a start is dropped |
| `settings.pause_seconds` | number | seconds | a closed-loop user's pause between traces |
| `settings.progress_seconds` | number | seconds | how often progress is printed |
| `settings.ramp_up_seconds` | number | seconds | time to raise the rate from zero |
| `settings.read` | boolean | - | whether reads were sent |
| `settings.read_min_age_seconds` | number | seconds | a trace is read only this long after it was sent |
| `settings.reads_per_second` | null | requests/s | the read rate, or null when no reads were sent |
| `settings.run_limit` | null | traces | stop after this many traces, or null for no limit |
| `settings.settle_seconds` | number | seconds | how long to wait for the stored count to reach the sent count |
| `settings.simulated_delay_ms` | number | milliseconds | added delay inside each run, to model a slow agent |
| `settings.traces_per_second` | null | traces/s | the open-loop rate, or null in users mode |
| `settings.users` | number | users | closed-loop users |
| `write` | object | - | what was sent |
| `write.achieved_traces_per_second` | number | traces/s | traces sent over the whole duration, ramp included |
| `write.dropped_starts` | number | traces | starts dropped for being over max_in_flight, never delayed |
| `write.duration_seconds` | number | seconds | wall time of the load |
| `write.first_error` | string or null | - | the first error message, or null |
| `write.mode` | string | - | open-loop (a rate) or closed-loop (users) |
| `write.run_errors` | number | errors | runs the SDK reported an error for |
| `write.runs_sent` | number | runs | runs in those traces |
| `write.schedule_lag_seconds` | object | - | how late each open-loop start was |
| `write.schedule_lag_seconds.max` | number | seconds | largest; null when nothing was measured |
| `write.schedule_lag_seconds.p50` | number | seconds | median; null when nothing was measured |
| `write.schedule_lag_seconds.p95` | number | seconds | 95th percentile; null when nothing was measured |
| `write.schedule_lag_seconds.p99` | number | seconds | 99th percentile; null when nothing was measured |
| `write.send_latency_seconds` | object | - | the time to hand a trace to the SDK |
| `write.send_latency_seconds.max` | number | seconds | largest; null when nothing was measured |
| `write.send_latency_seconds.p50` | number | seconds | median; null when nothing was measured |
| `write.send_latency_seconds.p95` | number | seconds | 95th percentile; null when nothing was measured |
| `write.send_latency_seconds.p99` | number | seconds | 99th percentile; null when nothing was measured |
| `write.steady_traces_per_second` | number or null | traces/s | traces sent after the ramp over its duration; null outside open-loop mode |
| `write.target_traces_per_second` | number | traces/s | the rate asked for, or null in closed-loop mode |
| `write.traces_sent` | number | traces | traces handed to the SDK |
| `write.traces_started` | number | traces | starts the schedule made, open-loop only |
| `write.tracing_enabled` | boolean | - | false means payloads were generated and nothing was uploaded |
| `feedback` | object | - | feedback writes |
| `feedback.errors` | number | errors | writes that failed or were still pending after the drain |
| `feedback.per_trace` | number | feedback/trace | the rate the profile asks for |
| `feedback.sent` | number | feedback | writes made |
| `reads` | object | - | reads sent |
| `reads.achieved_requests_per_second` | number | requests/s | reads made (errors included) over the duration |
| `reads.classes` | object | - | one entry per read class |
| `reads.classes.<class>` | object | - | one class: list_traces, read_trace, project_stats, feedback_stats or heavy_filter |
| `reads.classes.<class>.component` | string | - | the SmithDB component it exercises |
| `reads.classes.<class>.count` | number | requests | reads that succeeded and were timed |
| `reads.classes.<class>.errors` | number | errors | reads that failed |
| `reads.classes.<class>.first_error` | string or null | - | the first error message, or null |
| `reads.classes.<class>.p50_seconds` | number or null | seconds | median latency; null when none succeeded |
| `reads.classes.<class>.p95_seconds` | number or null | seconds | 95th-percentile latency; null when none succeeded |
| `reads.classes.<class>.p99_seconds` | number or null | seconds | 99th-percentile latency; null when none succeeded |
| `reads.classes.<class>.skipped` | number | requests | reads not made for want of a trace old enough |
| `reads.dropped` | number | requests | reads dropped for being over max_in_flight |
| `reads.enabled` | boolean | - | reads were sent |
| `reads.target_requests_per_second` | null | requests/s | the rate asked for, or null |
| `lag` | object | - | how long a sampled trace took to become readable, measured from the start of its send |
| `lag.deadline_seconds` | number | seconds | the deadline |
| `lag.max_seconds` | number | seconds | largest lag; null when none was readable |
| `lag.never_readable` | number | traces | sampled traces not readable by the deadline |
| `lag.p50_seconds` | number | seconds | median lag; null when none was readable |
| `lag.p95_seconds` | number | seconds | 95th-percentile lag; null when none was readable |
| `lag.p99_seconds` | number | seconds | 99th-percentile lag; null when none was readable |
| `lag.poll_errors` | number | errors | polls that failed |
| `lag.readable` | number | traces | sampled traces that became readable |
| `lag.sample_share` | number | fraction | the share of traces sampled |
| `lag.sampled` | number | traces | traces sampled |
| `stored` | object | - | runs sent against runs the project holds for this test's id |
| `stored.error` | string or null | - | why the stored count could not be read, or null |
| `stored.missing_runs` | number or null | runs | sent minus stored, never below zero; null when unread, which fails the run |
| `stored.runs_sent` | number | runs | runs handed to the SDK |
| `stored.runs_stored` | number or null | runs | runs stored; null when the count could not be read |
| `stored.settle_seconds` | number | seconds | how long the count was given to settle |
| `stored.traces_missing` | number or null | traces | sent minus stored, never below zero; null when unread |
| `stored.traces_sent` | number | traces | traces handed to the SDK |
| `stored.traces_stored` | number or null | traces | root runs stored; null when the count could not be read |
| `errors` | object | - | error totals |
| `errors.reads` | number | errors | read errors over all classes |
| `errors.upload` | number | errors | upload errors the SDK reported |
| `targets` | object | - | one verdict per promise; passed is null when nothing was measured, which neither passes nor fails the run |
| `targets.no_missing_runs` | object | - | every run sent is stored |
| `targets.no_missing_runs.missing` | number or null | runs | runs missing; null when the count could not be read |
| `targets.no_missing_runs.passed` | boolean or null | - | true, false, or null when unread |
| `targets.send_latency_limit` | object | - | the optional limit on the send latency |
| `targets.send_latency_limit.passed` | boolean or null | - | true, false, or null when no limit was set |
| `targets.stored_within_seconds_p99` | object | - | the lag's 99th percentile against the profile's target; over 1% never readable fails it |
| `targets.stored_within_seconds_p99.observed` | string | - | what was observed: lag_p99 |
| `targets.stored_within_seconds_p99.observed_seconds` | number | seconds | the observed 99th percentile; null when not measured |
| `targets.stored_within_seconds_p99.passed` | boolean | - | true, false, or null when not measured |
| `targets.stored_within_seconds_p99.target_seconds` | number | seconds | the target |
| `targets.trace_load_seconds_p99` | object | - | the read_trace 99th percentile against the profile's target |
| `targets.trace_load_seconds_p99.observed` | string | - | what was observed: read_trace_p99 |
| `targets.trace_load_seconds_p99.observed_seconds` | number or null | seconds | the observed 99th percentile; null without reads |
| `targets.trace_load_seconds_p99.passed` | boolean or null | - | true, false, or null when not measured |
| `targets.trace_load_seconds_p99.target_seconds` | number | seconds | the target |
| `server` | object | - | what the install said about itself |
| `server.app_version` | null | - | the LangSmith release it serves (its /info version), the images' version, not the chart's; null when tracing was off or the read failed |
| `passed` | boolean | - | every measured target met, nothing missing, and no run, feedback, upload, read or stored-count error |
